# PC 系统设置头像裁剪 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 PC 管理后台为系统设置头像提供本地上传、圆形取景框裁剪、上传和回填能力。

**Architecture:** 将图片缩放、拖动边界与 Canvas 输出计算放在独立工具模块，便于 Node 单测。`AvatarCropModal` 只负责选择文件、处理指针和滚轮事件、展示圆形取景框，并复用既有上传 API；`SiteManagement` 负责显示头像预览、打开弹窗和保存设置。

**Tech Stack:** Vue 3 Composition API、浏览器 Canvas、原生 Pointer Events、现有 Vite 与 Node test runner。

- [ ] **Step 3: 实现最小裁剪几何工具**

```js
export function coverScale(imageWidth, imageHeight, viewportSize) {
  return Math.max(viewportSize / imageWidth, viewportSize / imageHeight)
}

export function clampCropOffset(offset, renderedWidth, renderedHeight, viewportSize) {
  return {
    x: Math.min(0, Math.max(viewportSize - renderedWidth, offset.x)),
    y: Math.min(0, Math.max(viewportSize - renderedHeight, offset.y)),
  }
}

export function cropSourceRect(offset, scale, viewportSize) {
  return {
    sx: -offset.x / scale,
    sy: -offset.y / scale,
    size: viewportSize / scale,
  }
}
```

### Task 2: 头像裁剪弹窗组件

**Files:**
- Create: `src/components/AvatarCropModal.vue`
- Modify: `src/api/admin.js`

- [ ] **Step 1: 创建 `AvatarCropModal.vue` 的可访问弹窗结构**

弹窗接收 `visible`，发出 `close` 和 `uploaded(url)`；包含隐藏文件输入、“选择图片”“取消”“确认”按钮、固定 240px 圆形裁剪区域、图片层和圆形外遮罩。

- [ ] **Step 2: 接入文件加载与初始覆盖缩放**

使用 `URL.createObjectURL(file)` 加载图片，在 `img.onload` 中通过 `coverScale(image.naturalWidth, image.naturalHeight, 240)` 计算缩放，使用 `clampCropOffset` 让图片居中且完全覆盖取景框；替换或关闭时撤销对象 URL。

- [ ] **Step 3: 实现拖动与滚轮缩放**

在取景区使用 Pointer Events 记录起点，移动时按 `clampCropOffset` 更新偏移；滚轮事件以取景框中心调整缩放，最小缩放不小于初始覆盖比例，再次限制偏移。图片层通过 `transform: translate(...) scale(...)` 渲染。

- [ ] **Step 4: 实现确认裁剪和上传**

确认前无图片时调用 `showError('请先选择图片')`。使用 `cropSourceRect` 将当前视口绘制到 `320 x 320` Canvas，`canvas.toBlob` 生成 `avatar.png` 并调用 `uploadImage`；成功后发出 `uploaded(data.url)` 与 `close`，失败调用右下角通知并保持弹窗打开。

- [ ] **Step 5: 为弹窗编写样式**

使用当前全局变量、`Teleport` 与遮罩层层级。圆形窗口外使用径向遮罩变暗，取景框内保持清晰；拖动时禁用图片选中，按钮采用现有后台按钮视觉，窄屏弹窗不溢出。
