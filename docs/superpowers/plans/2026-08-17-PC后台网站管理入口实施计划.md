# PC 后台网站管理入口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 PC 后台增加可扩展的网站管理导航入口和空白页面。

**Architecture:** 新建独立的 `SiteManagement.vue` 作为未来站点设置功能的承载页，在现有 Vue Router 中注册 `/admin/site`，并在 `AdminLayout.vue` 的导航中添加入口。页面不请求接口，也不影响现有后台页面。

**Tech Stack:** Vue 3、Vue Router、Scoped CSS、Vite。
