# PC 系统设置头像裁剪设计

## 目标

管理员在“后台管理 / 网站管理”中设置前台“我的”页面头像时，可以上传本地图片、在圆形取景框内调整图片位置和缩放比例，并保存裁剪后的头像。

## 范围

- 仅修改 PC 管理后台的系统设置页面。
- 不修改 `blogweixin`。
- 不新增后端接口或数据库字段。
- 复用已有 `POST /api/admin/upload` 管理员图片上传接口，以及现有系统设置保存接口。

## 页面设计

系统设置的“头像地址”文本输入框替换为头像配置行：

- 左侧展示当前头像预览；未设置时展示前台已有的默认头像占位样式。
- 右侧提供“设置头像”按钮。
- 已保存的头像 URL 仍保存在 `site.author.avatar`，由页面底部的“保存配置”统一提交。

点击“设置头像”后，打开裁剪弹窗：

- 弹窗中央为固定尺寸的圆形取景框，取景框内区域对应最终头像。
- 圆形外部以半透明深色遮罩覆盖，取景框边缘清晰可见。
- 用户可点击“选择图片”选取本地图片，支持常见浏览器可读取的图片类型。
- 图片读取后按“覆盖取景框”的比例自动缩放并居中，保证圆形区域不会出现空白。
- 用户只能在取景框范围内通过拖动调整图片位置，并可通过滚轮缩放图片。
- 弹窗底部提供“取消”和“确认”操作。取消不改变系统设置；确认将当前圆形区域渲染为正方形图片后上传。

## 数据流

1. 选择本地文件后，浏览器使用对象 URL 加载图片，仅用于本地预览和裁剪。
2. 确认时使用 Canvas 按当前缩放与位置绘制圆形取景框对应的正方形图像，导出 PNG Blob。
3. 将 Blob 包装为图片文件，调用现有 `uploadImage` 请求上传。
4. 上传成功后，将返回的 URL 写入 `site.author.avatar`，关闭裁剪弹窗并更新设置页预览。
5. 管理员点击页面底部“保存配置”后，现有系统设置接口保存 `profile_avatar`。

## 错误处理

- 未选择图片直接确认时，右下角通知提示“请先选择图片”。
- 文件无法读取、Canvas 导出失败或上传失败时，右下角通知展示失败原因；弹窗保持打开，方便重新调整或更换图片。
- 裁剪过程不修改已保存的头像 URL；只有上传成功才回填新 URL。

## 验证

- 选择横图、竖图和小尺寸图片时，取景框均应无空白。
- 拖动和滚轮缩放可改变最终头像内容。
- 取消后设置页头像不变化。
- 确认上传成功后预览立即更新，点击“保存配置”并刷新页面后仍正确显示。
- 前端构建成功。
